# Source policy

Vertical SaaS Radar monitors public product signals. It is not a code aggregation project.

## Allowed default sources
- public release feeds;
- public changelogs;
- public API documentation updates;
- public repositories and release notes;
- public status or product-update feeds when their terms permit automated access.

## Not allowed in the default project
- private or login-only scraping;
- copied proprietary documentation archives;
- secrets, credentials or customer data;
- republishing third-party source material beyond the small excerpts needed for classification;
- bypassing rate limits or access controls.

Each adapter should keep a canonical evidence URL. If a source has licensing, trademark or terms-of-use constraints, those constraints remain with the source and must be respected.
