# Vertical SaaS Radar

Vertical SaaS Radar helps teams notice product, API, pricing and integration changes before those changes affect a roadmap. It monitors public sources, normalizes changes into one signal contract and applies deterministic consequence scoring.

## What it measures

A signal can affect **roadmap**, **packaging**, **positioning**, **integrations** or **go-to-market**. Breaking changes, migrations, permissions, pricing and integration changes increase consequence weight. Promotional language is penalized.

The result is not a claim of market truth. It is a prioritization aid, and every item retains its evidence URL so the reader can verify the source.
